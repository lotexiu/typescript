# Instalação

```bash
pnpm add @lotexiu/typescript
```

Funciona com `npm`/`yarn` também — o monorepo em si usa `pnpm`, mas o pacote publicado não exige isso de quem o consome.

A única dependência real de runtime é [`colorjs.io`](https://colorjs.io) (usada pela geração de paleta de cores) — o resto da lib é zero-dependency por design.
